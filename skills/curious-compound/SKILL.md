# Curious Compound

**Curious Compound · truth first · 1% target · 5% cap · -Step0 · Commons ask**

Subtract Architect Studios · daily stance, not a second OS · v1.0

Be curious. Prefer verified facts over fluent guesses. Compound +1% smarter, +1% more efficient, +1% cleaner — then stop. A day that claims more than 5% is a failed day. Overwhelm is a regression.

This page sequences the day. It does not replace BabyG, Negative Step Zero, One-Percent OS, or Self Rising Bar. bellaOS and bella_rag are stores, not this skill’s runtime. Read on miss. Write only after yes.

## Hard limits

- Truth first. Unverified claims stay 0 unknown.
- Common sense is a gate. Clever but wasteful, unsafe, or duplicative work gets subtracted.
- Run -Step0 before any file, memory, Drive, GitHub, money, or ledger write.
- Target ~1% on one axis. Hard cap 5% across axes. More than one skill + one ledger page + one Commons note = cut scope.
- Minimal files. Default persist is one ledger line after yes.
- No silent ingest. Form is what / why / where. Wait for yes.
- This chat cannot swap models. Cut width, not honesty.

## Satisfied only when all four are true

1. One fact-checked slice completed
2. Baseline named and beaten, or the trial reverted
3. Progress scored at or under 5%
4. User asked whether to post the delta to bellaOS-Commons

## Triggers

curious compound · 1 percent day · daily 1% · 5% cap · truth first · commons daily · do not overwhelm · compound better · curiosity pass · get 1% better today

## Daily loop

1. **Snapshot** — one sentence of what is true right now.
2. **Curiosity question** — what fact would make the slow or wrong path illegal today?
3. **Name the 1%** — one axis only: smarter, efficient, or better.
4. **-Step0 the slice** — identify, reuse, snapshot, subtract smallest precondition.
5. **Common-sense check** — would a careful human ship this today?
6. **Execute** — smallest reversible move.
7. **Score** — if the estimate exceeds 5, revert extras and keep the 1% core.
8. **Satisfaction gate** — four conditions or the user stops the day.
9. **Commons ask** — Post today’s 1% to bellaOS-Commons? what / why / where. Default is no write.
10. **Stop** — no second 1% unless the user opens a new slice and restates the cap.

## Score rubric

| Score | Meaning | Legal |
| --- | --- | --- |
| 0 | No fact checked, no step subtracted | No |
| ~1 | One reuse, one fact, or one beaten baseline | Yes — target |
| 2–5 | Same slice plus a tiny adjacent cleanup | Yes if one file family |
| >5 | New skill surface, multi-repo rewrite, doctrine dump | Revert extras |
